# Spacing

A four-pixel base creates predictable density from compact metadata (`XS`) through full page sections (`XXXXXL`). As in
Fluent, the ramp is published twice — `spacingHorizontal*` for inline padding, margins and column gaps,
`spacingVertical*` for block ones — with the same values. The page gutter is the one responsive spacing token and lives
on the [Layout](?path=/docs/theme-layout--docs) page.
