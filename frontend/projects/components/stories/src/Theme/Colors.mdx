# Colors

Warm, family, sun-dappled — calm, not corporate. Warm neutrals make the interface feel calm, **coral** identifies the one
next step on a screen, and **forest green** confirms decisions without feeling clinical.

Every swatch on this page is read from `saturdazeLightTheme` and painted with its live custom property, so the swatches
cannot drift from what the components render. Never hard-code a hex value in a component stylesheet — if a colour is
missing, add an alias token to the theme first (see [Overview](?path=/docs/theme-overview--docs)).

## Status

`Success` marks locked, confirmed and saved states. `Danger` is a gentle warning, not an alarming one: destructive buttons,
invalid fields and error banners.

## Weather & category tones
