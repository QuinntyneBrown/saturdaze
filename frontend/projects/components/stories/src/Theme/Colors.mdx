# Colors

Warm, family, sun-dappled — calm, not corporate. Warm neutrals make the interface feel calm, **coral** identifies the one
next step on a screen, and **forest green** confirms decisions without feeling clinical.

Every value on this page is read from `src/lib/styles/_tokens.scss` and painted with the live `var(--sd-*)` custom
property, so the swatches cannot drift from what the components render. Never hard-code a hex value in a component
stylesheet — if a colour is missing, add the token first.

## Brand

`--sd-primary` is the coral button — one per screen. `--sd-primary-deep` is the coral text that passes AA on
`--sd-primary-soft`. `--sd-accent` marks locked, confirmed and saved states.

## Weather & category tones

The chip, disc and avatar tones. Each tone has a saturated base, a `-soft` fill and an `-ink` text colour that passes
AA on the fill — always pair the fill with its ink.
