# Shadows

Elevation is soft and paper-like. As in Fluent, each shadow is named for its blur and built from
the theme's shadow colours: `shadow4` lifts cards off the cream page, `shadow16` marks hover and floating chrome (the
bottom nav), `shadow28` is reserved for dialogs and menus.
