# Layout

Saturdaze v2 is a full-width web app with a 1120px reading width — there is no phone canvas (ADR-009).

## Breakpoints

Breakpoints live SCSS-side in `_breakpoints.scss`; components use the `respond-to()` mixin so the constants stay in one
place.

| Tier    | Width       | Chrome                                         |
| ------- | ----------- | ---------------------------------------------- |
| xsmall  | 320–379px   | Display type one step down                     |
| phone   | &lt; 720px  | Floating bottom nav (`sd-bottom-nav`)          |
| tablet  | 720–1023px  | Sticky top bar, single column                  |
| desktop | ≥ 1024px    | Top bar, Saturday \| Sunday side by side       |

```scss
@use "breakpoints" as *;

.day-pair {
  display: grid;
  gap: var(--sd-s-4);

  @include respond-to(desktop) {
    grid-template-columns: 1fr 1fr;
  }
}
```

Use the toolbar's viewport menu (xsmall, mobile, tablet, desktop — the same sizes as the Playwright projects) to check a
story at each tier.
