# Motion

Motion is brief and useful: `--sd-dur-fast` for hover and press feedback, `--sd-dur-base` for state changes such as a
day locking or a dialog opening. Everything eases with `--sd-ease`. Under `prefers-reduced-motion: reduce` the global
stylesheet collapses every animation and transition to near zero.

Hover a row to see the duration.
