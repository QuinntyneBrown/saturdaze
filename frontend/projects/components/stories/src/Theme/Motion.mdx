# Motion

Motion is brief and useful: `durationFast` for hover and press feedback, `durationNormal` for state changes such as a
day locking or a dialog opening. Everything eases with `curveEasyEase`. Under `prefers-reduced-motion: reduce` the global
stylesheet collapses every animation and transition to near zero.

Hover a row to see the duration.
