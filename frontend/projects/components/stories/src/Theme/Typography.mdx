# Typography

A compact scale keeps phone planning comfortable while allowing confident editorial moments on the weekend and
landing screens. The stack is system-first: nothing web-loads Inter on purpose, so first paint never waits on a font.

## Font family

## Font sizes

A seven-step scale named on Fluent's ramp (`Base200`–`Base600`, `Hero700`–`Hero800`). The three display sizes step **up** from 1024px and the two largest step **down** on 320–379px
phones — the responsive retunes are listed under each token.

Unitless ratios, so one line height serves every size.
