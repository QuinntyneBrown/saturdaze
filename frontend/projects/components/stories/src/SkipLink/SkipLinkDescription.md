"Skip to content" (WCAG 2.4.1 Bypass Blocks). `sd-skip-link` renders the `.skip-link` from `docs/mocks/styles/app.css`: the first focusable element on every page, off screen at rest and shown 16px from the top left on `:focus-visible`, above the top bar, the bottom nav and any dialog.

Its href is the current pathname and query followed by the target fragment, so a native fallback stays on the same route despite both apps using `<base href="/">`. Activating it prevents navigation, gives the element whose id is `target` (`main` by default) `tabindex="-1"`, and focuses it, which also scrolls it into view clear of the sticky bar.
