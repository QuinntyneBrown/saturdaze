A segmented radio group for a choice between two or three short options — "Saturday | Sunday | Either". Every option stays visible, and the selected one fills in.

The host carries the `.field` block from `docs/mocks-v2/styles/app.css`; inside, `.field__label` labels a `.seg-radio` `role="radiogroup"` whose `.seg-radio__opt` labels wrap real `<input type="radio">`s sharing one generated `name`. Three or more options add `.seg-radio--3`. It implements `ControlValueAccessor` over the option's string `value` (there is no `value` input), so bind it with `formControlName`, `[formControl]` or `ngModel`, and disable it through the control.
