A quiet note block with a leading glyph — "Why this", "Locked", "The short version". The `sd-well` host carries `.well` and its tone modifier (`.well--accent`, `.well--warn`, `.well--primary`) from `docs/mocks-v2/styles/app.css`.

`icon` names the 16px leading `sd-icon` (default `sparkle`). The `title` input renders the bold `.well__title` first line; the default slot is the softer `.well__body` underneath. Note that `title` is also mirrored to the host's `title` attribute, so it doubles as a native tooltip.
