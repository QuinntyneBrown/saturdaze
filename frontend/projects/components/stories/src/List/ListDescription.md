A stack of rows. `sd-list` is a `role="list"` host carrying `.list` from `docs/mocks-v2/styles/app.css`; `card` adds `.list--card`, which draws the surface, border and radius and pads the rows.

Project `sd-list-item`s into the default slot. Each item brings its own leading slot (an avatar or disc), text and trailing slot, and can be a static row, a link or a button — see List Item.
