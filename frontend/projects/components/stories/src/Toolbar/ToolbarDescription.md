The row of fields above a list. `sd-toolbar` carries `.toolbar` from `docs/mocks/pages/admin.places.html`: its fields stack on phones and sit in one row from 720px, aligned on their bottom edge.

The default `search` layout gives the first field the room and the last a fixed 240px (search, then sort). `layout="fields"` gives every field the same width, up to 320px (a few filter selects).
