## Best practices

### Layout

- Project form fields only (`sd-text-input`, `sd-select`); filter chips belong in an `sd-filters` row under the toolbar.
- Put search first and sort last, so the eye reads "find, then order".

### Content

- Label every field, even the search box: the label is the field's name for screen readers and stays visible when the field has a value.
- Keep the toolbar's values in the address so a filtered view can be shared.
