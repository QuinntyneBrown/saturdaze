A labelled text field. `sd-text-input` renders the label (with an optional "Required" marker), a native `<input>` — or a `<textarea>` with `multiline`, set in monospace without wrapping or spellcheck with `code` — and one line underneath that is either the hint or the error.

The host carries the `.field` block from `docs/mocks/styles/app.css`; inner elements are `.field__label`, `.field__req`, `.field__input`, `.field__hint` and `.field__error`. A non-empty `error` (or the bare `invalid` flag) sets `aria-invalid` on the control, and the hint or error is wired up through `aria-describedby`. It implements `ControlValueAccessor`, so bind it with `formControlName` / `[formControl]` / `ngModel`; the static `value` input only seeds the field until the form writes to it. `type`, `autocomplete`, `name`, `min`, `max` and `step` are forwarded to the inner input so password managers and mobile keyboards behave.
