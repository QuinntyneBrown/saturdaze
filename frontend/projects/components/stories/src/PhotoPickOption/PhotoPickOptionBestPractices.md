## Best practices

### Content

- Always set `label`: it is the radio's accessible name. Repeat it as `caption` when sighted users need it too (place names, "Curated · …").
- Use `src` for photos the screen already sized for the tile, and `media` for catalog photos that carry a credit.

### Accessibility

- Do not put interactive content inside an option; the whole tile is the radio.
- Keep captions short; long ones are cut with an ellipsis.
