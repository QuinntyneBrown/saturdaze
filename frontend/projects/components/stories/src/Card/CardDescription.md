The all-purpose surface. `sd-card` is a plain container for dialogs, the review queue and Family; the typed cards (`sd-activity-card`, `sd-food-card`, `sd-event-card`, `sd-past-card`) own their own inner structure and reuse the same block.

The host _is_ the card: it carries `.card` from `docs/mocks-v2/styles/app.css` and each input toggles a host modifier — `.card--sunk`, `.card--pad-lg`, `.card--locked`, `.card--dimmed`, `.card--muted`, `.card--span` and `.card--interactive`. Everything you project goes in the default slot; the host is a column with a 10px gap. The `.card__*` element styles live with the typed cards, so a plain card's content is styled by the page that owns it (the stories use the global `sd-cluster` / `sd-text-*` utilities).
