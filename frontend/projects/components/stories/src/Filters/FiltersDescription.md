A labelled row of `sd-filter-chip`s. The host is a `role="group"` named by `label`, and carries one of two layout classes from `docs/mocks-v2/styles/app.css`: with `scroll` (the default) it is the full-bleed `.scroller-x` — a single horizontally scrolling line on phones with faded edges, wrapping from the 720px tablet breakpoint — and with `scroll` off it is the always-wrapping `.filters` row.

Project the chips in order; put `<span class="sd-vdivider"></span>` between chip groups.
