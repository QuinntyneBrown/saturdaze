A switch for a setting that takes effect straight away — "Remember me" on sign-in, the family's planning preferences. `label` renders the visible text; `srLabel` names the switch when the text lives elsewhere (a list row's title).

The inner `<label>` carries the `.toggle` block from `docs/mocks/styles/app.css`: a visually hidden `.toggle__input` (`<input type="checkbox" role="switch">`, so keyboard, focus and assistive tech come for free), the drawn `.toggle__track` and an optional `.toggle__label`. It implements `ControlValueAccessor` over a `boolean`. The static `checked` input seeds the state until a form control binds — then `writeValue` is authoritative. Disable it through the control.
