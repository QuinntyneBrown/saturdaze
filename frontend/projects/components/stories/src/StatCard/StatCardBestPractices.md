## Best practices

### Layout

- Place cards in a `.stat-grid`: one column below 1024px and three above, so the three catalogs sit side by side on a desktop and stack on a phone.

### Content

- Keep the flag lines in severity order (no photo, blocked URL, unreviewed, missing alt text) so the cards agree with the Places sort.
- Pass real counts, zero included; a line with "0" tells an administrator there is nothing to do, a missing line does not.
- Match `tone` to the catalog (`leaf` activities, `sun` restaurants, `sky` events) as the rest of the admin app does.
