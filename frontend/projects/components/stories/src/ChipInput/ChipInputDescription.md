A tag editor: the current values as removable chips, followed by a bare input that adds a value on Enter or comma (and on blur). Backspace in an empty input removes the last chip. The family's likes and dislikes are edited with it.

The host carries the `.field` block from `docs/mocks/styles/app.css` with a `.field__label` and a `.chip-input` box holding `sd-chip`s (`removable`, toned by `tone`) and the `.chip-input__field`. It implements `ControlValueAccessor` over `string[]`: values are trimmed, case-insensitive duplicates in this list or the paired list are rejected without clearing the draft, and a visible polite status announces conflicts, additions and removals. Set `otherValues` and `otherLabel` to reject values already in the paired list. There is no `value` input — bind it with `formControlName`, `[formControl]` or `ngModel`.
