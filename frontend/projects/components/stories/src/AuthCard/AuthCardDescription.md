The card that sits inside `sd-auth-shell`: a heading block (optional disc, the page's `<h1>`, a subtitle), the projected form or buttons, and an "alt" line that links to the neighbouring task ("New here? Create an account").

The host carries `.auth-card` from `docs/mocks-v2/styles/app.css`. Inputs: `title` (rendered as the `<h1>` — the card *is* the page heading), `subtitle`, and `center` to centre the head for status cards. Slots: `[slot=disc]` (an `sd-disc` or `sd-spinner` above the title), `[slot=head]` (extra head content), the default slot (form, banner, buttons) and `[slot=alt]` — the alt paragraph hides itself when nothing is projected.
