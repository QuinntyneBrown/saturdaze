## Best practices

### Layout

- Give it the full content width; the grid is one column below 720px and two above, with the cover spanning both.

### Content

- Pass the place's primary photo unchanged (`src`, `alt`, `width`, `height`, `credit`); the previews must show the real crop and the real credit.
- Match `tone` and `icon` to the place's category so the fallback is the one families would get.
