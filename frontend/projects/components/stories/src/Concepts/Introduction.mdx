## Principles

- **The mocks are the source of truth.** `docs/mocks` is the design (ADR-009). Components carry the mocks' BEM
  classes verbatim, so one set of Playwright locators and visual baselines serves both the mocks and the app.
- **One coral button per screen.** Coral (`--colorBrandBackground`) marks the single next step; everything else is quiet.
- **Warm, not loud.** Cream surfaces, soft radii, paper-like shadows and a gentle warning colour.
- **State is ARIA.** Selection, pressed and invalid states are `aria-current`, `aria-pressed`, `aria-invalid` and
  `role="switch"` — never a class alone.
- **Phone first, full width later.** A floating bottom nav below 720px, a sticky top bar above it, Saturday | Sunday side
  by side from 1024px.
