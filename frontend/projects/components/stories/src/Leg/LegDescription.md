A travel leg between two timeline blocks. The `sd-leg` host carries `.leg` from `docs/mocks/styles/app.css`: a dotted rail in line with the block discs, the drive as "45 min · 40 km" and, for legs over ten minutes, a "Directions" link that opens the maps provider in a new tab (L2-102).

The host is a list item named for assistive tech ("Travel: 45 minutes, 40 kilometres to Lavender fields"), so it sits in the same `role="list"` as the `sd-block` rows around it. Legs replace the old standalone "Drive to …" blocks.
