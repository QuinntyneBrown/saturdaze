One row of an `sd-list`. The host is `role="listitem"`; the inner row carries `.list__item` from `docs/mocks/styles/app.css` and is a `<button>` when `action` is set (emitting `pressed`), an in-app `<a>` when `href` is set (routed through the Angular router), otherwise a plain `<div>`. Interactive rows add `.list__item--action`.

The text column (`.list__text`) renders `title` as `.list__title` and `subtitle` as `.list__sub` — or the subtitle first with `subtitleFirst`, for a label over a value — followed by any default-slot content. Project avatars or discs into `[slot=leading]` and chips, toggles or buttons into `[slot=trailing]` (`.list__trail`); `chevron` adds the trailing arrow.
