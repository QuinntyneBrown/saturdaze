# User journeys

Ordered by value added to the product, highest first. Estimates are days for an intermediate developer. Completion reflects gaps in `detailed-design-drift-audit.md`; every gap behind these journeys was closed on 2026-10-18.

| Add an idea to a day | Add any idea to Saturday or Sunday with preview | 3 | 100% |
