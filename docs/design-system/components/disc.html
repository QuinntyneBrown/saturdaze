Component · Data display

Disc

A disc is an icon in a tinted circle. It leads a list row, a card head or an empty state so a parent can scan by shape and colour: a lock for commitments, a pin for home, sun or cloud for the day's weather, a date tile for an event.

Overview

Three related markers share this page. None of them is a control: a disc sits inside a row, card or heading that is the control (or is plain content), and the text beside it carries the meaning.

  • Disc (.disc) is the leading icon of a list row ("Swim lessons", "Port Credit, Mississauga"), a card head (La Marina in dialog D12) or the hero icon of an empty state and an auth card ("Check your email").
  • Weather disc (.weather-disc) leads each day header on Weekend with the forecast: sun for Saturday, cloud for Sunday. The temperature is always written beside it.
  • Date tile (.date-tile) shows the month and day of an event on Ideas → Events and on Review submissions. The full date is always in the card meta.

Use an avatar for a person, a media frame or its fallback tile for a place's photo, and a chip when the marker needs a word. A disc never becomes a button on its own; if it must act, use an icon-only button.

Anatomy

  1. ContainerCircle (--borderRadiusCircular) sized by --sd-disc-size, filled with the tone's Background1 tint.
  2. Icon20px stroke icon in the tone's Foreground1 (26px in --xl), aria-hidden="true".
  3. Month.date-tile__m: 12px bold uppercase, wide tracking (was 10px, drift D12).
  4. Day.date-tile__d: 17px bold. The tile is a 44px rounded square in the brand tint.

Variants

The tone says what kind of thing the row is about, and matches the chip and filter tones used elsewhere. Keep one meaning per tone across the product.

Neutral (home, generic), accent (commitments, done), primary (calendar, highlight), warn (expired, failed), sun (food, seasonal), sky (travel), leaf (outdoor, likes), indoor (errands), surface (on a tinted well).

Sizes

Default (36px) leads list rows. Small (32px) fits dense rows and dialog lists; large (40px) leads card heads; extra large (56px) is the hero icon of an empty state or auth card. Weather discs are 40px; date tiles are 44px.

States

A disc has no pointer or focus state of its own: the row or card around it takes hover and focus. It does have a loading form (a skeleton circle while the row loads) and a busy form (.spinner-disc, a spinner ring around the icon while the planner works).

Both themes

May17
May17
  • Row hovered: the disc keeps its tint while the row's subtle background changes around it, so the icon stays readable.
  • Loading: .skeleton--disc holds the space at the same size, so rows do not jump when they arrive.
  • Busy: .spinner-disc wraps a 40px spinner ring round a 16px icon; it appears in the generating state of Weekend. The status text sits in a live region beside it.

Responsive behaviour

  • Discs keep their size at every width; they are flex: none, so the row text wraps before a disc shrinks.
  • The weather disc sits at the left of the sticky day header at every width. The day header's actions collapse to icons under 720px; the disc does not.
  • Date tiles stay 44px from 360px up; at 200% text zoom the month and day grow with the root font size because the type tokens are in rem (drift D24).

Theming

The disc reads three component tokens: --sd-disc-size, --sd-disc-bg and --sd-disc-fg. Each tone maps them to a Background1 / Foreground1 pair (status or palette), so a theme only changes alias tokens. A local re-skin overrides the component tokens:

/* A disc on a sunk card keeps an edge */
.card--sunk .disc { --sd-disc-bg: var(--colorNeutralBackground1); }

In the dark theme the tints become deep, low-chroma fills and the icons lighten (for example sky 950 fill with sky 200 icon), keeping each pair above 4.5:1. The date tile uses the brand tint and brand foreground in both themes.

Accessibility

Role and pattern

No ARIA pattern applies: discs are images, not widgets. Choose one of two treatments:

  • Decorative (almost always): the text beside says the same thing, so the disc is aria-hidden="true". Every mock use is decorative: the lock beside "Swim lessons", the sun beside "17 May · 22° / 14°", the date tile beside "Sat 20 Jun".
  • Meaningful (rare): when the disc is the only carrier, give the wrapper role="img" and an aria-label ("Sunny, 22 degrees"). Prefer adding visible text instead.

Keyboard

KeyAction
TabNever stops on a disc. Focus lands on the row link or card action that contains it.

Focus

Not focusable. When the containing row is focused, the shared ring wraps the whole row, disc included.

Labelling

Write the meaning into the row: "Swim lessons · Saturdays · 9:00 to 10:00" rather than relying on the green lock. A date tile is hidden because the card meta repeats the full date with the weekday ("Sat 20 Jun"); a screen reader would otherwise hear "Jun 20" twice.

Motion

Discs do not move. The busy spinner keeps turning under prefers-reduced-motion because it reports status (drift D29); the skeleton shimmer stops.

Touch

Discs are not targets. The row that holds one is at least 56px tall (.list__item), well over the 24px minimum.

Content

  • One icon per disc, chosen from the icon set; never letters (those are avatars) or numbers (those are timeline stops).
  • Pick the icon for the thing, not the action: a pin for Home, a lock for a commitment, a bag for an errand.
  • Date tile month is the three-letter English abbreviation ("Jun"), uppercase by CSS, not typed in capitals. The day has no leading zero ("6", not "06").
  • Weather text beside a weather disc follows "Sunny · 22° / 14°": condition, then high / low.
