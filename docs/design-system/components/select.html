Select

A select picks one value from a fixed list: how long an errand takes, how to sort places, which administrator's changes to show. Saturdaze uses the browser's own select, styled to match the text field.

WCAG 2.2 AAStatus: stableAngular: sd-selectNative <select>

Overview

Use a select for five or more options where only one can be chosen and the options are short text. For two to four options show them all with a radio group or seg-radio (D18's Day, Saturday or Sunday, is a seg-radio for that reason). For several choices use checkboxes or filter chips; to trigger actions, a menu.

Why native

  • Phones open their own picker (a wheel on iOS, a sheet on Android) that is large, familiar and thumb-friendly. A custom dropdown would be worse on exactly the devices most families use.
  • Keyboard and screen readers work without any ARIA: type-ahead, arrow keys, announcements of the value and the number of options.
  • Forms submit, reset and validate (required) with no script.
  • The cost is that the open list cannot be styled. That is fine: options are short text. If options ever need icons, descriptions or search, use a combobox (APG Combobox), not a restyled select.

Anatomy

  1. LabelFrom the form field wrapper, always visible.
  2. Selected valueBody 1 (15px), 12px from the left; 36px kept clear on the right for the chevron.
  3. Chevron16px, drawn as a background image 12px from the right. It is decoration; the element is the control.

Variants

With a value: D7 Add an errand; AD3 Edit photo details.
HTML
<div class="field">
  <label class="field__label" for="d7-mins">Roughly how long</label>
  <select class="field__input" id="d7-mins">
    <option>15 min</option><option>30 min</option><option selected>45 min</option>…
  </select>
</div>

Placeholder option

When there is no sensible default, start with an empty option that asks the question. Make it value="" so required catches it; keep it selectable (not disabled) so the person can clear an optional choice.

A new photo with no licence yet. The empty option reads as a prompt, in the value colour, because it is a real choice.

Filters on admin toolbars

Admin Places (search and sort) and Activity log (place and administrator filters). The first option is the unfiltered default ("All places", "Everyone").

Sizes

One size: 44px tall, the same as the text field, so a select and an input in one row line up. Width follows the column; on admin toolbars the sort and filter selects take a fixed 240px from 720px so the list below does not shift when the value changes.

States

Hover and focus are forced with data-state. A select has no read-only state in HTML; show a fixed value as text, or as a read-only text field.

Both themes

  • Open is drawn by the browser or the phone, not by Saturdaze. It follows the theme's color-scheme.
  • Disabled fades to 50% and leaves the tab order. Prefer hiding a select that cannot apply.

Responsive behaviour

  • Under 720px selects are full width; admin toolbars stack the search and the select.
  • From 720px the toolbar puts search and sort on one row, with the select at 240px.
  • On phones the platform picker opens over the page; the long value is truncated in the closed select but shown whole in the picker.

Theming

The select is a .field__input: same fill, value colour, --sd-field-border and focus halo as the text field. The chevron is an inline SVG with a fixed mid-grey stroke, so it does not follow a theme change; it measures about 3.7:1 on the light fill and about 4.6:1 on the dark fill, so it is acceptable in both. A future version should draw it with mask and currentColor.

Accessibility

Role and pattern

Native <select> (role combobox or listbox, depending on the browser). No ARIA is added. If a custom picker is ever needed, follow the APG Listbox or Select-only Combobox pattern.

Keyboard

KeyAction
Tab / Shift+TabInto and out of the select.
Space / Alt+↓Opens the list.
↑ / ↓Moves through options (on Windows, also changes the value while closed).
Home / EndFirst / last option.
LettersType-ahead to the matching option ("C" for "CC BY 4.0").
Enter / EscChooses / closes without changing.

Focus

The field ring (focus border plus 3px halo). Changing the value never moves focus, navigates or submits (3.2.2). Admin filters update the list below in place and announce the new count in the toolbar's live region ("4 places").

Labelling

A visible <label for>, even on toolbars ("Sort", "Place", "Administrator"). Errors and hints are joined with aria-describedby; required is set alongside the "Required" marker.

Motion

Border and halo transition over --durationFast; zero with reduced motion. The open list is the platform's.

Touch

44px tall; the whole box, chevron included, opens the picker.

Content

  • Options are short and parallel: "15 min", "30 min", "45 min"; not "15 minutes", "Half an hour".
  • Order options in their natural order (time, size), otherwise by how often they are picked; alphabetical only for long name lists.
  • The unfiltered default names what it shows: "All places", "Everyone"; never "None" or "Select".
  • A placeholder option asks: "Choose a licence".
  • Sort labels say the order: "Worst health first", "Recently changed".
