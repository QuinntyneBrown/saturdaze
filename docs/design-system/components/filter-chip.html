Filter chip

Filter chips narrow a list in place: Outdoor ideas, Favourite weekends, places with no photo. Each chip is a toggle button that says whether it is on.

WCAG 2.2 AAStatus: stableAngular: sd-filter-chip, sd-filtersNative <button aria-pressed>

Overview

Use filter chips above a list or grid when people narrow it by a few known facets and see the result at once. They live in a .filters row (or a .scroller-x on phones) labelled as a group.

  • Toggle (<button class="filter-chip" aria-pressed>) is the default: Ideas, Past and admin Places. The list updates in place; nothing navigates.
  • "All" comes first and is pressed when no other chip is. Pressing it clears the others; pressing any other chip releases "All".
  • Link form (<a class="filter-chip" aria-current="page">) is for filters that change the URL and load a new view, such as "This weekend" and "Next weekend" on Events. Only one is current.
  • Chips within one facet are either-or or additive; say which by grouping them between .filters__divider lines (admin Places: kind | photo problem | primary source).

Use segments to switch between whole sections (Activities, Food, Events), a select for more than about eight options, and a static chip to describe an item.

Anatomy

  1. Leading icon (optional)14px, currentColor, aria-hidden="true"; 6px gap.
  2. Label--typographyLabel at 13px (--fontSizeBase300). It is the accessible name.
  3. ContainerPill, 32px (--controlHeightSmall), 1px accessible border when off; tone fill plus an ink-coloured border when pressed (drift D26).

Variants

Neutral and tinted

Off, every chip looks the same: transparent with a grey outline. On, a neutral chip fills with ink; a tinted chip fills with its tone, matching the static chip tones of the items it shows (Outdoor in leaf, Restaurants in sun).

Pressed: neutral (ink), leaf, indoor, sky, sun, accent, primary.
HTML
<button class="filter-chip" type="button" aria-pressed="true">All</button>
<button class="filter-chip filter-chip--leaf" type="button" aria-pressed="false">Outdoor</button>
<button class="filter-chip filter-chip--primary" type="button" aria-pressed="false">
  <svg class="icon" aria-hidden="true"><use href="#i-heart"/></svg>Favourites</button>

Grouped with dividers

Admin Places: the kind (either-or) and photo problems (additive) split by a 20px divider, hidden from assistive tech.

Sizes

One size: 32px tall (--controlHeightSmall), 12px side padding, 13px label. Filter chips sit above content and must not compete with page actions, so they are smaller than a medium button; 32px still clears the 24px target minimum with 8px between chips.

Same height as a small button, so a filter row and a "Clear" button line up.

States

Pointer and focus states are forced with data-state; pressed and disabled use the real aria-pressed and disabled attributes. Hover only changes an unpressed chip (border and label darken); a pressed chip keeps its fill.

Both themes

  • Pressed fills the chip and, for tinted chips, draws the border in the tone's ink colour, so "on" is not a pale fill alone (drift D26).
  • Disabled (50% opacity, not focusable) is for a facet that would return nothing; prefer showing the chip with a zero result and an empty state, which explains why.
  • Loading: the chip toggles at once; the list below shows its own loading state (skeleton). The chip never shows a spinner.

Responsive behaviour

  • Under 720px the user-facing filter rows (Ideas, Past) sit in a .scroller-x: one line, scrolling sideways, bleeding to the screen edges with a 16px fade so a cut-off chip hints there is more.
  • From 720px the same row wraps (.scroller-x turns into a wrapping row with no bleed or fade).
  • Admin Places uses a wrapping .filters row at every width; admins scan all the facets at once.
  • Labels never truncate. Put "All" first so it is always visible without scrolling.
Past filters in a 360px frame. Below 720px this row scrolls; on a wider screen it wraps.

Theming

The chip reads two component tokens for its pressed look, --sd-fchip-on-bg and --sd-fchip-on-fg. Neutral maps them to the inverted pair (--colorNeutralBackgroundInverted / --colorNeutralForegroundInverted); each tint maps them to a palette or status pair. The pressed tinted border reuses --sd-fchip-on-fg. The off state reads --colorNeutralStrokeAccessible and --colorNeutralForeground2.

To add a tone, map the two component tokens to an existing palette or status pair. The sample below is hypothetical: .filter-chip--example does not exist in components.css; only the tones listed under Variants do.

/* HYPOTHETICAL: .filter-chip--example does not exist. Shape of a new tone only. */
.filter-chip--example { --sd-fchip-on-bg: var(--colorStatusDangerBackground1); --sd-fchip-on-fg: var(--colorStatusDangerForeground1); }

In the dark theme the inverted pair flips to a light fill with a dark label, so a pressed neutral chip is the brightest thing in the row in both themes.

Accessibility

Role and pattern

Each chip is a native <button type="button"> with aria-pressed, the toggle form of the APG Button pattern. The row is role="group" with an aria-label ("Filters", or better "Idea filters"). Do not use aria-selected or role="tab": chips are not tabs and several can be on at once. The link form is a plain <a href> inside a labelled <nav>, with aria-current="page" on the current one.

Keyboard

KeyAction
Tab / Shift+TabMoves through every chip in order (no roving tabindex; rows are short).
Space / EnterToggles the chip and updates the list. Focus stays on the chip.
EnterOn the link form: follows the link.

Focus

The shared ring (2px --colorStrokeFocus2, 2px offset) on :focus-visible. In a .scroller-x the browser scrolls the focused chip into view; the scroller's inline padding keeps the ring from being clipped at the edge.

Labelling

The visible label is the name and does not change when pressed; aria-pressed carries the state ("Outdoor, toggle button, pressed"). Symbols get words: the Past "5★" chip needs aria-label="5 stars" or, better, the visible label "5 stars". After the list changes, announce the new count in a polite live region ("6 ideas"), as the tables and lists pattern describes.

Motion

Background, colour and border change over --durationFast (120ms). Under prefers-reduced-motion the duration token is zero and the change is instant. Results are not animated in.

Touch

32px tall with 8px between chips: above the 24px minimum, and the gap stops a thumb hitting two chips at once. The scroller lets people swipe the row without toggling a chip, because a toggle needs a tap, not a drag.

Content

  • Name the facet, not the action: "Outdoor", "Under 30 min", "No photo". Never "Show outdoor".
  • "All" (or "All kinds" when there are several facets) first.
  • One to three words, sentence case, words over symbols: "5 stars", not "5★".
  • Keep a row to about eight chips; past that, use a select or a filter dialog.
