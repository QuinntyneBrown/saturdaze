List

A list is a column of like rows: the four people in the family, the commitments every weekend works around, the places an admin needs to fix. Each row has a leading picture, a title, an optional second line and an optional trailing hint.

Overview

Use a list when every row has the same shape and a person reads down it, then opens one. Use cards when items need photos and their own actions and are compared side by side; use a table when people compare values across several columns; use a description list for label and value pairs about one thing.

  • Static rows (.list__item on the <li>) show facts: the family's home location, the "What" and "When" of an added errand.
  • Action rows (.list__item--action on an <a> or <button> inside the <li>) open something: a member's edit dialog, a commitment, a place. A chevron says "opens".
  • In a card (.list--card) the rows sit on a white surface with padding; that is the default on pages. A plain list (.list alone) lives inside a surface that already exists, such as a dialog.
  • Place row: the admin Places list adds a 4:3 thumbnail (.place-thumb) and health flags (.place-row__flags).

Anatomy

  1. Leading (optional)An avatar (people), a disc (things) or a place thumbnail. Decorative: aria-hidden="true".
  2. Title.list__title, --typographySubtitle1; wraps, never truncates.
  3. Second line (optional).list__sub, --typographyBody2 in the secondary colour.
  4. Trail (optional).list__trail: a chevron on action rows, or a short value; --colorNeutralForeground3.
  5. RowThree-column grid (leading, text, trail), at least 56px tall, 12px gap, hairline between rows.

.list--card clips its children (overflow: hidden) to keep its rounded corners, so rows in a card draw the focus ring inside the row (inset offset) where the clip cannot cut it. Rows in a plain list keep the 2px outside offset.

Responsive behaviour

  • Lists are one column at every width; on wide screens they sit in a page column (family-grid puts Who's in beside Home and Likes from 1024px) rather than stretching.
  • Titles and second lines wrap and break long words (overflow-wrap: anywhere), so an email address never pushes the trail off a 360px screen.
  • The leading element and the trail never shrink; the text column takes the rest.
  • Place rows keep their 72px thumbnail on phones; flags wrap under the second line.

Theming

The list reads alias tokens only. In a card it uses the card surface (--colorNeutralBackground1) and hairline (--colorNeutralStroke2); hover is --colorSubtleBackgroundHover and selected --colorBrandBackground2, both of which darken to warm umber and deep coral in the dark theme while the title stays --colorNeutralForeground1. Leading avatars keep their person tone in both themes.

Accessibility

Role and pattern

A native <ul> of <li>, so screen readers say "list, 4 items". On an action row the control is a real <a href> (it opens a dialog route or a page) or <button> (it acts in place) inside the <li>; the <li> itself is never the control. This is not the APG Listbox: a listbox is a single-select form widget with arrow-key navigation, and these rows are independent links. If a list ever becomes a choice (pick one member), use a radio group instead.

Keyboard

KeyAction
Tab / Shift+TabOne stop per action row; static rows are skipped.
EnterOpens the row (link or button).
SpaceActivates a button row (selection, sheet commands).

Focus

Action rows draw the shared 2px --colorStrokeFocus2 ring round the whole row. In a .list--card the ring sits inside the row (inset offset) so the card's rounded clip does not cut it; in a plain list the 2px offset works because the row has room around it.

Labelling

The row's text is its name: "Quinn, Parent · 38". Avatars, discs, thumbnails and the chevron are hidden from assistive tech. Give the <ul> a name when the section heading does not already introduce it (aria-labelledby the section title). Flag chips are plain text in the name ("Snug Harbour, Restaurant · 0 photos, No photo"). A count of results above an admin list is a role="status" line ("8 places") so filtering announces the new count.

Motion

The hover tint fades over --durationFast; zero under prefers-reduced-motion.

Touch

Every action row is at least 56px tall and full width, well above the 44px comfortable target. Never put a second control inside an action row; put row actions in the dialog it opens.

Content

  • Title: the person's or thing's name ("Mae", "Swim lessons", "Port Credit, Mississauga").
  • Second line: the facts that tell rows apart, joined with a middle dot: "Kid · 5", "Saturdays · 9:00 to 10:00", "Restaurant · 0 photos". No full stop.
  • Order: say it in the section sub when it is not obvious: parents first then kids by age; admin lists "worst photo health first".
  • Flags: one or two words naming the problem ("No photo", "Blocked URL", "Missing alt text"), or "Healthy".
