How to use

  1. Link the stylesheets in this order: tokens/tokens.css, then assets/components.css. Load assets/icons.js for the icon sprite.
  2. Use the classes exactly as each component page's Code section shows. They are the mocks' BEM classes, which are also the parity contract with the Angular components and the e2e locators (ADR-009).
  3. Read tokens by role, never by value: var(--colorBrandForeground1) for brand text, --colorBrandBackground for fills, --colorNeutralStrokeAccessible for input edges. The names match the product's generated _tokens.scss (ADR-013).
  4. Consume tokens/tokens.json (DTCG) on other platforms. Regenerate it with python docs/design-system/tokens/export_tokens.py after editing tokens.css.
  5. Press t or use the toggle to switch themes; every token table and contrast ratio on these pages updates live.
