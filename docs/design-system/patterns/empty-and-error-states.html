Pattern

Empty and error states

An empty screen is a moment to explain, not a dead end. Each one says what will be here, why it is not yet, and offers one thing to do next.

Overview

Empty and error states are built from one empty state block (.empty) with a disc, a title, a body, one action and an optional note. Full-page failures use the error page. Saturdaze does not use illustrations: an icon in a tinted disc carries the mood, and the copy does the work.

The formula, every time:

  1. Title: the state in plain words. "Nothing here yet", "Queue is clear".
  2. Body: why, and what happens next. "Plan this weekend and it shows up here on Monday, ready to rate."
  3. One action that moves the person on. Primary only on first run; quiet everywhere else.
  4. Note (optional): the alternative. "Or wait for Friday at 6pm."

An empty state replaces the content, not the page: the page header, navigation and any toolbar stay, so the person can change what they asked for.

Responsive behaviour

  • The block is centred and capped (30rem, 35rem for warm) at every width; at 360px it fills the content column with 24px inner padding.
  • Compact states stretch to the width of the list or grid they replace, so the layout does not jump when results come back.
  • Action buttons keep their natural width; they do not stretch on phones, because there is only one.
  • The error page centres in at least 60% of the viewport height so it never sits under the bottom nav.

Accessibility

Role and pattern

An empty state is a <section> labelled by its title (an h2 on a real page). A state that appears because of something the person did (filters emptied the list, a region failed) is announced through the page's status region: "No ideas match", "Events did not load". First-run and nothing-yet states are part of the page and are not announced.

Keyboard

KeyAction
TabReaches the one action after the filters or header that precede it.
EnterActivates the action.

Focus

Focus is not moved to an empty state. After "Clear filters", focus moves to the first filter chip (the button that was pressed is gone). The error page's h1 is its title, and the skip link still leads to #main.

Labelling

Discs and status numbers are aria-hidden; the title says it in words. Link text names the destination: "Go to this weekend", "Back to Family".

Motion

None. Empty states appear without animation so they are not mistaken for something loading.

Touch

Actions are 40px (32px for compact) and stand alone, with no neighbouring targets.
