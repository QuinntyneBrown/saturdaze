Design drift · Video 33

D38: errors that say warning, once

The alert icon instead of the close glyph, and role="alert" without aria-live

What drifted

The icon

× on an error

The close glyph means dismiss; banners and field errors used it as a status icon

The announcement

role + aria-live

role="alert" aria-live="assertive": the role already is an assertive live region

Why it matters

  • One icon, one meaning: a cross only ever says close
  • WCAG 4.1.3 status messages: announced without moving focus; role="alert" does this alone
  • A second declaration adds nothing and risks a double announcement

1 · Requirement, then mock

L2-136

An error banner and a field error use the alert icon, never close. An error banner is announced by role="alert" alone, with no aria-live.
