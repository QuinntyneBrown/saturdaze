D04: hint text too faint to read

Grey #9CA3AF was 2.38 to 2.54:1; hint text is now #636A77 at 4.75:1 on wells

What drifted

--sd-ink:         #1F2937;
--sd-ink-soft:    #6B7280;
--sd-ink-faint:   #9CA3AF;
  • Mocks: placeholders, field__req, block__dur, empty__note, auth__foot, site-footer, hero__note, list__trail
  • Product: --colorNeutralForeground3: #9ca3af
  • Design system: logged as D04, fixed on its own side

Why it matters: WCAG 1.4.3 (AA)

Before

#9CA3AF

2.54 / 2.38 / 2.22:1

White / canvas / wells; fails 4.5:1

After

#636A77

5.44 / 5.09 / 4.75:1

White / canvas / wells; passes AA

Where hint text sits

  • Foreground1 #1F2937: content
  • Foreground2 #6B7280: labels and metadata (D05 darkens it next)
  • Foreground3 #636A77: hints, placeholders, durations, footers
  • #9CA3AF: disabled things only, never live text
