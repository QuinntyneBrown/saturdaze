Loop or table?

Loop

One test · stops at the first failure · one name in the report

A quick sweep

describe.each

One test per row · every row runs · each failure named

Rows you would otherwise write by hand

Similar is not identical

  • refresh: maps any 401 onto token_expired
  • login: falls back to invalid_credentials when the body carries no code
  • A table would need expected-result columns and branches in the body

it.each / test.each repeat one test — same rules, not used here yet.

Pitfalls

  • Calling the code under test while building the table
  • One shared title for every row
  • Columns that switch the body's behaviour
  • Rows too long to read at a glance

Things to remember

One block per row: 4 rows × 2 tests = 8
as const keeps rows typed tuples
%s first column · %# index
Wrap calls in arrow functions
Identical behaviour only
Loop = one test · table = many
