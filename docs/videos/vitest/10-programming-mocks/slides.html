Pitfalls

  • A permanent form where you meant Once: the retry fails too
  • Unconsumed Once values wait for the next call
  • Rejecting with Error when the real dependency rejects with a plain object
  • No safe default on the base mock

Things to remember

Return · resolved · rejected · implementation
Once answers the next call, in order
Once → permanent → original
Safe default in beforeEach
A never-resolving promise freezes loading
