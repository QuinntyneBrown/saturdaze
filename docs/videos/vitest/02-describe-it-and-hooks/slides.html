Async tests are awaited

Return a promise

Forget an await

The test finishes green; the real assertion runs later, or never

Two ways to clean up

afterEach

Automatic, covers every test in the block — for cleanup most tests need

try / finally

Keeps the cleanup next to the one test that made the mess

Both are fine. Leaving the mess is not.

Why cleanup matters here

Fake timers left on

Every setTimeout in the next spec file freezes

A console spy left mocked

Real errors vanish from unrelated tests

isolate: false — spec files share one module context.

Pitfalls

  • Mutable state assigned in a describe body runs once, at collection
  • Read-only is fine: const day = projectDay(weekendDto(), 'Saturday') in weekend-projection.spec.ts
  • Forgetting to await in a test or a hook
  • Assertions inside hooks
  • Tests that depend on another test running first

Things to remember

describe groups, it states one behaviour
Async tests and hooks are awaited
Outer setup first, teardown in reverse
afterEach verifies and restores
