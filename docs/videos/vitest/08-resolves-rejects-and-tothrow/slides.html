A throw inside an async method

async regenerate(id?: string): Promise<void> {
  const target = this.targetId(id);
  await this.send(
    'regenerate',
    this.http.post<WeekendDto>(`${this.baseUrl}/api/weekends/${target}/regenerate`, {}),
  );
}

private targetId(id?: string): string {
  const target = id ?? this._dto()?.id;
  if (!target) throw new Error('No current weekend is loaded yet.');
  return target;
}

Plain-object rejections

The auth service rejects with AuthError objects, so its spec uses toEqual / toMatchObject

Pitfalls

  • No await on resolves/rejects: Vitest 4.1 warns and auto-awaits at the end; the next major fails
  • Awaiting before flushing the HTTP request: a hang
  • Passing a value to toThrow instead of a function
  • toThrow on an async function instead of rejects
  • rejects.toBeTruthy when the error's shape is the contract

Things to remember

Always await expect(…).resolves / .rejects
resolves.toBe: identity · toBeUndefined: no value
Assert the rejection's shape when callers depend on it
HTTP specs: call · flush · await
toThrow takes a function; synchronous only
Async throw = rejection: rejects.toThrow
