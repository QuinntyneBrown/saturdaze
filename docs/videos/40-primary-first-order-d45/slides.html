D45: focus that follows what you see

The primary action first in the DOM, so Tab matches the phone layout

What drifted

On screen (phone)

  1. Share (primary)
  2. Add to calendar

CSS order: -1 draws the primary first

In the mock's DOM

  1. Add to calendar
  2. Share (primary)

So Tab visits Add to calendar first

Why it matters

  • WCAG 2.4.3 focus order; 1.3.2 meaningful sequence
  • Keyboard and switch users follow the DOM, not the CSS
  • The primary action should be the first stop
