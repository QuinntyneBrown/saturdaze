D06: control edges

Field borders and the off switch track were 1.36:1; controls now use #80868F at 3.20:1 or more

What drifted

--sd-line:        rgba(31, 41, 55, 0.08);
--sd-line-strong: rgba(31, 41, 55, 0.16);
  • Mocks: field borders, the chip input, the off switch track
  • Product: the same controls read colorNeutralStroke1, 16% ink
  • Design system: colorNeutralStrokeAccessible, logged as D06

Why it matters: WCAG 1.4.11 (AA)

Before

16% ink

1.36 / 1.36 / 1.36:1

White / canvas / wells; fails 3:1 everywhere

After

#80868F

3.67 / 3.43 / 3.20:1

White / canvas / wells; passes 3:1 everywhere

Control edge or decoration?

Accessible stroke

  • Fields, chip input, select
  • Off switch track
  • Off filter chips, unpressed votes
  • Dashed add rows, upload tiles

Stays decorative

  • Card edges and hovers
  • Filter group divider
  • Quiet button: D28, its own fix
