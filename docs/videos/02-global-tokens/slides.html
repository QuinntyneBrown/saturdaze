The rule

Components never read global values. Missing a colour? Add an alias token for that role and regenerate.

Things to remember

Write the types first — mistakes fail at compile time
A brand ramp is a scale to pick from
Globals may be named by value; aliases by role
Ramp names are ranks, not pixel values
Base spacing is private; two axes, two decisions
Layout and z-index are tokens too
