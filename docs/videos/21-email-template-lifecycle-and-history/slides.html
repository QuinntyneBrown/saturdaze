Three statuses, one action each

Draftbeing written · offers Activate
→
Activesenders may use it · offers Archive
→
Archivedretired, readable · offers Restore as draft

Every change is a version

  • Draft, version 1
  • Activate: version 2
  • Archive: version 3
  • Restore as draft: version 4

Always active

  • Save changes, History, Duplicate
  • No Archive, no Delete
  • The API refuses both: system_template

Delete (AD8)

  • Names the template, its key and versions
  • Cannot be undone; Archive keeps it
  • One DELETE, back to the list

Things to remember

Draft · Active · Archived; one action each; each change a new version.
System templates stay active and cannot be deleted.
Delete removes the history too; Archive keeps both.
Every change is a revision; loading one saves as the next version.
A sender finds an Active template by key and uses the preview's renderer.
