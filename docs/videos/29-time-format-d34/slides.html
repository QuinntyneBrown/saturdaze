D34: one clock

Two formats

Why it matters

  • "11:00 to 1:00" could be eleven at night
  • Two clocks on one screen make people convert
  • Screen readers read the missing suffix as ambiguously as it looks

The rule

A time

9:15am · 6:30pm

A range

11:00am to 1:00pm

1 · format.ts

/** A 12-hour range with am or pm on both ends: "9:00am to 10:00am", "11:00am to 1:00pm". */
export function timeRange(start: string, end: string): string {
  return `${clock12(start)} to ${clock12(end)}`;
}

hhmm is removed; the timeline clock, Keeping notes, errand placement and admin stamps call clock12.
