L1-037: Family Member Sign-In and Ownership

  • The account that creates a family owns it
  • The owner invites members, who sign in with their own email and password
  • The owner adds members, such as young children, who never sign in
  • The owner removes members, which ends their sign-in
  • Only the owner changes who belongs to the family

private static FamilyMemberDto ToDto(
    FamilyMember member,
    IReadOnlyDictionary<Guid, string> invited,
    IReadOnlyDictionary<Guid, string> accounts)
{
    if (member.UserId is { } userId && accounts.TryGetValue(userId, out var account))
        return new FamilyMemberDto(member.Id, member.Name, member.Age, MemberAccess.Account, account);
    if (invited.TryGetValue(member.Id, out var email))
        return new FamilyMemberDto(member.Id, member.Name, member.Age, MemberAccess.Invited, email);
    return new FamilyMemberDto(member.Id, member.Name, member.Age);
}

One check: EnsureOwnerAsync

public async Task<Family> EnsureOwnerAsync(CancellationToken ct)
{
    var familyId = await _family.GetCurrentFamilyIdAsync(ct);
    var family = await _db.Families
        .Include(f => f.Members)
        .SingleOrDefaultAsync(f => f.Id == familyId, ct)
        ?? throw new NotFoundException(nameof(Family), familyId);

    if (!IsOwner(family))
        throw new ForbiddenException("owner_only", "Only the family's owner can change who's in.");
    return family;
}

Things to remember

The creator owns the family through OwnerUserId; older families got their earliest account.
Every member is None, Invited or Account, derived from links.
Only the owner changes who's in; anyone else gets 403 owner_only.
No email means a member who is planned for and never signs in.
