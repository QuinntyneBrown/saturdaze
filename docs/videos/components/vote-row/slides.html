Coding sd-vote-row

Thumbs up, thumbs down, one output.

Where it lives: inside sd-food-card

  <sd-vote-row
    [votes]="votes()"
    [disabled]="votesDisabled()"
    [label]="'Family vote for ' + cardTitle()"
    (voteChange)="voteChange.emit($event)"

Rendered on every card of the food ideas page.

Types first

export type Vote = 'up' | 'down' | 'none';

export interface VoteCell {
  readonly name: string;
  readonly tone: AvatarTone;
  readonly vote: Vote;
}

The decorator: a labelled group

@Component({
  selector: 'sd-vote-row',
  standalone: true,
  imports: [Avatar, Icon],
  templateUrl: './vote-row.html',
  styleUrl: './vote-row.scss',
  changeDetection: ChangeDetectionStrategy.OnPush,
  host: {
    class: 'vote-row',
    role: 'group',
    '[attr.aria-label]': 'label()',
  },
})

Only class and ARIA on the host: no [attr.disabled] (ADR-009). Disabled lands on each button.

Inputs and one output

  readonly votes = input<readonly VoteCell[]>([]);
  readonly label = input<string>('Family vote');
  readonly disabled = input(false, { transform: booleanAttribute });
  readonly voteChange = output<{ index: number; vote: Vote }>();

Controlled: emit the next vote

  protected cast(index: number, direction: 'up' | 'down'): void {
    if (this.disabled()) return;
    const current = this.votes()[index]?.vote ?? 'none';
    this.voteChange.emit({ index, vote: current === direction ? 'none' : direction });
  }

No signal(), no model() — the votes array is never mutated.

The parent owns the truth

clickcast(i, 'up')
→
voteChange{ index, vote }
→
parent savesnew votes array
→
votes()OnPush re-render

Server-owned data: controlled input + output beats two-way model().

Pitfalls

  • Never mutate votes — emit, and let the parent pass a new array
  • Track by name, not index
  • Every icon-only button needs its own aria-label

Things to remember

Exported types shared with the parent
Controlled: inputs in, one output() out
role="group" + label; aria-pressed per thumb
Pressed styles read aria-pressed, fill + ink pairs
Spec proves clear-on-repeat with a spy
