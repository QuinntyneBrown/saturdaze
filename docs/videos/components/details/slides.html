Coding sd-details

Label and value pairs from one typed, read-only array input.

Where the app uses it

              <sd-details [items]="details(card)" />

Location · Cost · Ages · Link · Notes

An exported item type

export interface DetailItem {
  readonly label: string;
  readonly value: string | null;
  readonly href?: string | null;
}
  • value: null → the family didn't give it
  • href set → the value becomes a link

The decorator

@Component({
  selector: 'sd-details',
  standalone: true,
  imports: [Icon],
  templateUrl: './details.html',
  styleUrl: './details.scss',
  changeDetection: ChangeDetectionStrategy.OnPush,
  host: {
    class: 'details',
  },
})

Two inputs

export class Details {
  readonly items = input<readonly DetailItem[]>([]);
  readonly missing = input<string>('Not given');
}

readonly DetailItem[]

The component promises not to mutate the parent's array

No computed, no state, no output

Per-item decisions read best in the template

The template

@for (item of items(); track item.label) {
  <dt class="details__label">{{ item.label }}</dt>
  @if (item.href && item.value) {
    <dd class="details__value">
      <a class="details__link" [attr.href]="item.href" target="_blank" rel="noopener">
        {{ item.value }}
        <sd-icon name="arrow_right" [size]="12" [stroke]="2" />
      </a>
    </dd>
  } @else if (item.value) {
    <dd class="details__value">{{ item.value }}</dd>
  } @else {
    <dd class="details__value details__value--faint">{{ missing() }}</dd>
  }
}

Safe links, never empty

  • target="_blank" always with rel="noopener"
  • href without a value → the faint placeholder, not an empty link

A semantics caveat

Today

<sd-details> → <dt>/<dd> children, no <dl>, no role

Option

Render a real <dl> in the template, or give the host a fitting role

Then: ignores an href without a value — no anchor, faint placeholder

Pitfalls

  • target="_blank" without rel="noopener"
  • Empty links
  • Mutating the items array
  • <dt>/<dd> outside a real <dl>
  • One-off media queries

Things to remember

Exported type, read-only array input
@for + @if / @else if / @else
rel="noopener", no empty links
Configurable, live placeholder
overflow-wrap: anywhere
