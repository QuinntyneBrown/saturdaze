# Components series

One instructional video per component in `frontend/projects/components/src/lib/`. Each video builds the component step by step from its real source (`.ts`, `.html`, `.scss`), calls out the best practices it follows (above all signal inputs, `computed()`, `model()`, `output()`, signal queries and OnPush), and then walks through its unit tests (`.spec.ts`).

Each folder holds `script.md`, `slides.html` and `README.md` (outline), plus the generated `<name>.mp3` and `<name>.mp4`. Build them the same way as the other videos (see [../README.md](../README.md)), passing the nested folder, e.g. `docs/videos/components/button`.
