Coding sd-dialog

A presentational panel for CDK dialogs: sheet on phones, modal from 720px.

Where it is used

<sd-dialog title="Rename this weekend" [subtitle]="data.eyebrow">
  <form class="form" (submit)="save($event)">
    …
  </form>
  <sd-button slot="actions" variant="quiet" type="button" (click)="cancel()">Cancel</sd-button>
  <sd-button slot="actions" variant="primary" type="button" (click)="save()">Save</sd-button>
</sd-dialog>

Also: confirm, share, rating, add-errand, commitment, calendar… (app/dialogs/)

Who owns what

CDK Dialog

  • backdrop
  • focus trap, restore focus
  • Escape
  • role="dialog" container

sd-dialog

  • the panel
  • title, subtitle, close ×
  • body + action row
  • labels the container

Opened with shared options

/** The options every app dialog opens with. */

Rule: use CDK Dialog/Overlay — never hand-roll a modal.

Host bindings read signals

  • .dialog — the BEM block from docs/mocks/styles/app.css (ADR-009)
  • Modifiers dialog--specimen, dialog--wide from isStatic(), wide()
  • Inputs are not reflected to host attributes — only classes and ARIA (ADR-009)

inject(), optional where it may be missing

export class Dialog {
  private readonly host = inject<ElementRef<HTMLElement>>(ElementRef);
  private readonly ref = inject(DialogRef, { optional: true });

No DialogRef in Storybook or the /dialogs gallery.

Signal inputs

  readonly staticMode = input(false, { alias: 'static', transform: booleanAttribute });
  private readonly forcedStatic = inject(SD_DIALOG_STATIC, { optional: true }) ?? false;
  /** Inline when the `static` input or the `SD_DIALOG_STATIC` provider says so. */
  readonly isStatic = computed(() => this.staticMode() || this.forcedStatic);
  readonly dialogTitle = input<string>('', { alias: 'title' });
  readonly subtitle = input<string>('');
  /** 520px panel for forms. */
  readonly wide = input(false, { transform: booleanAttribute });
  readonly closeLabel = input<string>('Close');
  /** Emits when the × is pressed; the CDK ref (if any) is closed too. */
  readonly closed = output<void>();

An injection token + computed()

export const SD_DIALOG_STATIC = new InjectionToken<boolean>('SD_DIALOG_STATIC');
        { provide: SD_DIALOG_STATIC, useValue: true },

isStatic = computed(() => staticMode() || forcedStatic) — one derived value for host and template.

output(), not @Output()

  readonly closed = output<void>();

Typed, no EventEmitter; consumers bind (closed)="…".

Labelling the CDK container

  /** Unique id of the `<h2>`; the CDK container's `aria-labelledby` points at it. */
  protected readonly titleId = `sd-dialog-title-${nextDialogId++}`;

  constructor() {
    afterNextRender(() => {
      const container = this.host.nativeElement.closest('[role="dialog"], [role="alertdialog"]');
      if (container && !container.hasAttribute('aria-labelledby')) {
        container.setAttribute('aria-labelledby', this.titleId);
      }
    });
  }

afterNextRender vs effect()

afterNextRender

Runs once, in the browser, after the first render. One-time DOM work.

effect()

Re-runs when signals change. Nothing here to react to.

  protected close(): void {
    this.closed.emit();
    this.ref?.close();
  }

Accessibility and slots

  • gives the heading an id and does not nest a dialog role of its own
  • labels the surrounding CDK container with its heading
  • leaves an existing aria-labelledby on the container alone
  • projects body, left action and actions into their regions
  • Dialog inside a CDK dialog · closes the CDK ref when the × is pressed

Pitfalls

  • Opening from the component — use CDK Dialog.open + shared options
  • Adding role="dialog" to the panel
  • An effect() for one-time DOM work
  • One @if around several [slot=…] nodes (NG8011)

Things to remember

Presentational; the CDK owns modal behaviour
Aliased inputs + booleanAttribute
computed() merges input + token
output() + optional DialogRef
afterNextRender labels the container
Tokens by role · BEM · slots once
