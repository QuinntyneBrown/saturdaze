Coding sd-stars

Five stars that display a rating, or become a radio group to edit it.

Two modes in the app

<button class="card__rate" type="button" [attr.aria-label]="rateLabel()" (click)="rate.emit()">
  <sd-stars [rating]="rating() ?? 0" [label]="ratingLabel()" />
</button>
  <sd-stars size="lg" editable [rating]="rating()" (ratingChange)="rating.set($event)" />

The decorator: role from a signal

@Component({
  selector: 'sd-stars',
  standalone: true,
  imports: [Icon],
  templateUrl: './stars.html',
  styleUrl: './stars.scss',
  changeDetection: ChangeDetectionStrategy.OnPush,
  host: {
    class: 'stars',
    '[class.stars--lg]': 'size() === "lg"',
    '[attr.role]': 'editable() ? "radiogroup" : null',
    '[attr.aria-label]': 'editable() ? groupLabel() : null',
  },
})

Five inputs, one output

export class Stars {
  readonly rating = input<number>(0);
  /** Caption after the stars in display mode ("5 of 5", "Rate it"). */
  readonly label = input<string>('');
  readonly size = input<'md' | 'lg'>('md');
  readonly editable = input(false, { transform: booleanAttribute });
  readonly groupLabel = input<string>('Rating');
  readonly ratingChange = output<number>();

Derived state and methods

  protected readonly steps = [1, 2, 3, 4, 5];
  protected readonly iconSize = computed(() => (this.size() === 'lg' ? 24 : 18));

  protected pick(step: number): void {
    this.ratingChange.emit(step === this.rating() ? 0 : step);
  }

  protected starLabel(step: number): string {
    return step === 1 ? '1 star' : `${step} stars`;
  }

Editable: five radio buttons

@if (editable()) {
  @for (step of steps; track step) {
    <button
      class="stars__btn"
      type="button"
      role="radio"
      [attr.aria-checked]="step === rating()"
      [attr.aria-label]="starLabel(step)"
      (click)="pick(step)"
    >
      <sd-icon name="star" [size]="iconSize()" [filled]="step <= rating()" />
    </button>
  }

Pitfalls

  • Clicks only emit — the parent must feed rating back
  • Five tab stops, no arrow keys: the full radio keyboard pattern isn't implemented
  • Captions are display-mode only

Things to remember

rating + ratingChange = banana-in-a-box
model() only if the component writes
computed() icon size; plain steps array
Host role + label from a signal
One aria-checked, many filled
Spec covers both modes
