Coding sd-text-input

A labelled field that speaks Angular forms.

Where it lives

      <sd-text-input
        label="Email"
        type="email"
        name="email"
        autocomplete="email"
        formControlName="email"
        [invalid]="!!errorMessage() || (form.controls.email.invalid && form.controls.email.touched)"
      />

sign-in · create-account · reset-password · add-errand, commitment, family-member dialogs …

Plugging into forms

  providers: [
    {
      provide: NG_VALUE_ACCESSOR,
      useExisting: forwardRef(() => TextInput),
      multi: true,
    },
  ],
})
export class TextInput implements ControlValueAccessor {

Signal inputs

  readonly label = input<string>('');
  readonly value = input<string>('');
  readonly placeholder = input<string>('');
  readonly type = input<string>('text');
  readonly hint = input<string>('');
  /** Inline error; non-empty also sets `aria-invalid`. */
  readonly error = input<string>('');
  readonly required = input(false, { transform: booleanAttribute });
  /** Mark invalid without an inline message (a form-level error banner). */
  readonly invalid = input(false, { transform: booleanAttribute });
  readonly multiline = input(false, { transform: booleanAttribute });
  readonly rows = input<number>(3);
  readonly readonly = input(false, { transform: booleanAttribute });

Forwarded to the inner control

  // Forwarded to the inner control so password managers and autofill
  // recognise sign-in / sign-up fields.
  readonly autocomplete = input<string>('');
  readonly name = input<string>('');
  readonly min = input<string | number | null>(null);
  readonly max = input<string | number | null>(null);
  readonly step = input<string | number | null>(null);

Local state: plain strings and writable signals

  protected readonly id = `sd-field-${nextFieldId++}`;
  protected readonly hintId = `${this.id}-hint`;
  protected readonly errorId = `${this.id}-error`;
  protected readonly internalValue = signal<string>('');
  protected readonly disabled = signal<boolean>(false);

Never changes → plain field. Changes → signal().

Derived state with computed()

  protected readonly describedBy = computed(() => {
    const ids: string[] = [];
    if (this.error()) ids.push(this.errorId);
    if (this.hint()) ids.push(this.hintId);
    return ids.length ? ids.join(' ') : null;
  });

Pure, cached, recalculated only when error or hint change.

One effect: seed from value

  constructor() {
    effect(() => {
      const v = this.value();
      if (v) this.internalValue.set(v);
    });
  }

Why not computed?

Two writers: the input and the form

Keep effects rare

Only for syncing state a derivation can't express

The accessor methods

  protected handleInput(event: Event): void {
    const v = (event.target as HTMLInputElement | HTMLTextAreaElement).value;
    this.internalValue.set(v);
    this.onChange(v);
  }

  protected handleBlur(): void {
    this.onTouched();
  }

  writeValue(value: string | null): void {
    this.internalValue.set(value ?? '');
  }

  setDisabledState(isDisabled: boolean): void {
    this.disabled.set(isDisabled);
  }

The template: label and control

@if (label()) {
  <label class="field__label" [attr.for]="id">
  …
} @else {
  <input
    class="field__input"
    [id]="id"
    [attr.type]="type()"
    [value]="internalValue()"
    [attr.placeholder]="placeholder() || null"
    …
    [attr.aria-invalid]="error() || invalid() ? 'true' : null"
    [attr.aria-describedby]="describedBy()"
    [attr.aria-required]="required() ? 'true' : null"
    (input)="handleInput($event)"
    (blur)="handleBlur()"
  />

Error replaces hint

@if (error()) {
  <p class="field__error" [id]="errorId">
    <sd-icon name="close" [size]="12" [stroke]="2" />
    {{ error() }}
  </p>
} @else if (hint()) {
  <p class="field__hint" [id]="hintId">{{ hint() }}</p>
}

Rendering and ARIA wiring

  • creates an unlabelled text field
  • links the label to the control and marks required fields
  • describes the control with its hint
  • shows the error instead of the hint and flags the control invalid
    expect(control().getAttribute('aria-describedby')).toBe(
      `${control().id}-error ${control().id}-hint`,
    );

Forwarding inputs

  • forwards type, placeholder, autocomplete, name and numeric bounds
  • renders a textarea with the given rows when multiline
  • seeds the control from the static value input

Driving the accessor

  it('reports typing and blur back to the form', () => {
    const onChange = vi.fn();
    const onTouched = vi.fn();
    component.registerOnChange(onChange);
    component.registerOnTouched(onTouched);

    control().value = 'abc';
    control().dispatchEvent(new Event('input'));
    expect(onChange).toHaveBeenCalledWith('abc');

    control().dispatchEvent(new Event('blur'));
    expect(onTouched).toHaveBeenCalledTimes(1);
  });

Also: writes form values into the control · disables the control from the form

Pitfalls

  • value="" doesn't clear — only non-empty values seed. Reset through the form.
  • Keep label, hint and error inside the component so the ids stay wired.

Things to remember

NG_VALUE_ACCESSOR + forwardRef + multi
booleanAttribute for bare attributes
signal() local state; computed() describedBy
One effect() seeds the value
States on real attributes, tokens by role
