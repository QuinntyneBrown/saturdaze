Eleven inputs, two outputs

  readonly cardTitle = input<string>('', { alias: 'title' });
  readonly meta = input<string>('');
  readonly tone = input<DiscTone>('default');
  readonly topPick = input(false, { transform: booleanAttribute });
  readonly locked = input(false, { transform: booleanAttribute });
  /** "Locked for lunch" / "Locked for dinner". */
  readonly lockedLabel = input<string>('Locked');
  readonly dimmed = input(false, { transform: booleanAttribute });
  readonly menuUrl = input<string>('');
  /** The restaurant's primary photo; null shows the fallback tile (L2-106). */
  readonly media = input<CardMedia | null>(null);
  readonly votes = input<readonly VoteCell[]>([]);
  readonly votesDisabled = input(false, { transform: booleanAttribute });
  readonly voteChange = output<{ index: number; vote: Vote }>();
  readonly lockIn = output<void>();

A typed, read-only array

export type Vote = 'up' | 'down' | 'none';

export interface VoteCell {
  readonly name: string;
  readonly tone: AvatarTone;
  readonly vote: Vote;
}

An input nobody reads

tone

Declared, bound by the ideas food page, never read in food-card.html.

Why it matters

Every input is public API. Remove it, or use it.

<sd-media class="card__media" [photo]="media()" tone="sun" icon="fork" />

Report, don't decide

sd-vote-row(voteChange)
→
sd-food-cardvoteChange · lockIn
→
ideas-food pagevote() · lockIn()

No computed(), inject() or local signal().

One state chip at most

<div class="card__head">
  <div class="card__head-text">
    <h3 class="card__title">{{ cardTitle() }}</h3>
    @if (meta()) {
      <p class="card__meta">{{ meta() }}</p>
    }
  </div>
  @if (locked()) {
    <sd-chip tone="accent"
      ><sd-icon name="lock" [size]="13" [stroke]="2" />{{ lockedLabel() }}</sd-chip
    >
  } @else if (topPick()) {
    <sd-chip tone="primary">Top pick</sd-chip>
  }
</div>

The footer

<div class="card__footer card__footer--between">
  @if (menuUrl()) {

  } @else {
    <span></span>
  }
  @if (!locked()) {
    <sd-button variant="primary" size="sm" [disabled]="dimmed()" (click)="lockIn.emit()">

States and outputs

  • renders the style line and the See menu link
  • labels the See menu link with its text
  • marks the top pick with a spanning card and a primary chip
  • shows a locked pick with the accent border, chip and no lock button
  • dims siblings of a locked pick and disables their lock button
  • emits lockIn when the primary button is pressed
  • renders the family vote row and relays its votes
  • projects chips into the chip row

Pitfalls

  • Deciding locking inside the card
  • Handling a nested output instead of relaying it
  • Inputs the template never reads (tone)

Things to remember

3 booleans → 3 BEM modifiers
@if / @else if: one state chip
voteChange relays a typed payload
lockIn reports a press
readonly VoteCell[] input
