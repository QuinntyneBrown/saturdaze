Coding sd-auth-card

Four slots and a centred head.

Where it lives

<sd-auth-card title="Check your email" subtitle="The link works for 30 minutes." center>
  <sd-disc slot="disc" icon="mail" tone="primary" size="xl" />
  <span slot="head" class="email-chip"
    ><sd-icon name="mail" [size]="16" />{{ maskedEmail() }}</span
  >
  <sd-button … >…</sd-button>
  <a slot="alt" class="sd-link" routerLink="/sign-in">Back to sign in</a>
</sd-auth-card>

Also: sign-in, create-account, verify-email

The decorator

@Component({
  selector: 'sd-auth-card',
  standalone: true,
  templateUrl: './auth-card.html',
  styleUrl: './auth-card.scss',
  changeDetection: ChangeDetectionStrategy.OnPush,
  host: {
    class: 'auth-card',
  },
})

Inputs stay inputs

Not on the host

[attr.title], [attr.center] — nothing read them; a reflected title means a native tooltip

On the host

Classes and ARIA state only (ADR-009). center becomes .auth-card__head--center in the template.

Three inputs

export class AuthCard {
  readonly cardTitle = input<string>('', { alias: 'title' });
  readonly subtitle = input<string>('');
  readonly center = input(false, { transform: booleanAttribute });
}

<sd-auth-card … center> → center() is true

Keep layout components small

No output()

The projected form owns its submit

No computed()

Nothing to derive

The page owns the behaviour; the card owns the frame.

The projection contract

expect(head.querySelector('.auth-card__title')?.textContent?.trim()).toBe('Welcome back');
expect(head.lastElementChild?.classList.contains('head-a')).toBe(true);

expect(el.querySelector(':scope > .form-a')).not.toBeNull();
expect(el.querySelector('.auth-card__alt .alt-a')?.textContent).toBe('Create an account');

Pitfalls

  • One @if around several slotted nodes (NG8011)
  • A second <h1> inside the projected form
  • Dropping booleanAttribute from center

Things to remember

The host is the card: auth-card
Aliased title, subtitle, center
booleanAttribute for the bare flag
disc · head · default · alt, each once
Alt line hides itself when empty
One test guards the slot order
