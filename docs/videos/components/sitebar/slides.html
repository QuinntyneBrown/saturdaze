A host class, not a reflected attribute

Before

'[attr.cta]': 'cta() ? "" : null' read by :host([cta])

Now

'[class.sitebar--cta]': 'cta()' read by :host(.sitebar--cta)

ADR-009: inputs stay inputs; only classes and ARIA state go on the host. data-scrolled stays — the mock sets it too.

One input

export class Sitebar {
  readonly cta = input(false, { transform: booleanAttribute });
}
  • <sd-sitebar cta /> → true
  • No output, model or local state

The Scrolled directive

@Directive({
  selector: '[sdScrolled]',
  standalone: true,
  host: {
    '[attr.data-scrolled]': 'scrolled() ? "" : null',
  },
})
export class Scrolled {
  private readonly zone = inject(NgZone);
  private readonly destroyRef = inject(DestroyRef);

  readonly scrolled = signal(false);

Outside the zone, signal on change

  constructor() {
    afterNextRender(() => {
      const update = (): void => {
        const next = window.scrollY > 4;
        if (next !== this.scrolled()) this.zone.run(() => this.scrolled.set(next));
      };
      this.zone.runOutsideAngular(() => {
        window.addEventListener('scroll', update, { passive: true });
      });
      this.destroyRef.onDestroy(() => window.removeEventListener('scroll', update));
      update();
    });
  }

High-frequency events

  1. Listen outside the zone, passive
  2. Derive the state you care about
  3. Write a signal only when it flips
  4. Clean up with DestroyRef

Faking the scroll

  it('fades in its backdrop once the page scrolls', () => {
    Object.defineProperty(window, 'scrollY', { value: 30, configurable: true, writable: true });
    window.dispatchEvent(new Event('scroll'));
    fixture.detectChanges();
    expect(host.getAttribute('data-scrolled')).toBe('');
    Object.defineProperty(window, 'scrollY', { value: 0, configurable: true, writable: true });
  });

Reset the shared window so later tests start clean.

Pitfalls

  • Don't add sdScrolled by hand — it's a host directive
  • Scroll listeners inside the zone, or a signal write per event
  • Hiding Sign in without the hero repeating it

Things to remember

booleanAttribute input → host class for CSS
hostDirectives compose shared behaviour
Outside the zone; signal on change
Layout tokens align with the page
Spec fakes scrollY and resets it
