The whole component

@Component({
  selector: 'sd-status-row',
  standalone: true,
  imports: [Spinner],
  templateUrl: './status-row.html',
  styleUrl: './status-row.scss',
  changeDetection: ChangeDetectionStrategy.OnPush,
  host: {
    class: 'status-row',
    role: 'status',
    'aria-live': 'polite',
  },
})
export class StatusRow {
  readonly icon = input<string>('sparkle');
}

A polite live region

role="status"

Advisory information, not an alert

aria-live="polite"

Announced after what the user is hearing — never interrupts

Static host attributes: written once, no signal to read.

One input, a sensible default

  readonly icon = input<string>('sparkle');
  • The planner's case needs nothing extra
  • No output, model, local state or computed

The template

<sd-spinner [icon]="icon()" />
<span class="status-row__text"><ng-content /></span>
  • A non-empty icon makes the spinner a .spinner-disc
  • One default slot, declared once, never conditional

Pitfalls

  • Live regions inserted with their text may not be announced — keep the region mounted when you can
  • No buttons or links inside a status region
  • Errors belong in <sd-banner role="alert">

Things to remember

Static host attrs → polite live region
One input, default 'sparkle'
Spinner decorates; text informs
One slot, never conditional
Spec guards role, default, forwarding, projection
