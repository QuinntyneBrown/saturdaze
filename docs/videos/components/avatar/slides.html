Coding sd-avatar

A computed initial and host class bindings.

Where it lives

<sd-avatar slot="leading" [name]="member.name" [tone]="member.tone" size="lg" />
<sd-avatar
  class="photo-picker__preview"
  tone="primary"
  [name]="data.name"
  [src]="previewUrl()"
/>

Also: sd-top-bar, sd-vote-row, review-submissions

The decorator

@Component({
  selector: 'sd-avatar',
  standalone: true,
  templateUrl: './avatar.html',
  styleUrl: './avatar.scss',
  changeDetection: ChangeDetectionStrategy.OnPush,
  host: {
    class: 'avatar',
    'aria-hidden': 'true',
    /* … modifiers … */
  },
})

Decorative: the name is always written next to it.

One class binding per modifier

    '[class.avatar--sm]': 'size() === "sm"',
    '[class.avatar--md]': 'size() === "md"',
    '[class.avatar--xl]': 'size() === "xl"',
    '[class.avatar--q]': 'tone() === "primary"',
    '[class.avatar--s]': 'tone() === "leaf"',
    '[class.avatar--e]': 'tone() === "sky"',
    '[class.avatar--m]': 'tone() === "sun"',
    '[class.avatar--indoor]': 'tone() === "indoor"',

q · s · e · m = Quinn · Sara · Eli · Mae — the mock's class names, kept verbatim (ADR-009)

Photo modifier — and nothing else

    '[class.avatar--photo]': '!!src()',
  },
})

No [attr.name], [attr.tone], [attr.size]: inputs stay inputs — only classes and ARIA state on the host (ADR-009).

Four typed inputs

export type AvatarTone = 'default' | 'primary' | 'leaf' | 'sky' | 'sun' | 'indoor';
export type AvatarSize = 'sm' | 'md' | 'lg' | 'xl';
…
export class Avatar {
  readonly name = input<string>('?');
  readonly tone = input<AvatarTone>('default');
  /** sm 24px · md 28px · lg 32px (default) · xl 36px. */
  readonly size = input<AvatarSize>('lg');
  /** Profile photo URL; when set it is shown instead of the initial. */
  readonly src = input<string | null>(null);

The computed initial

  protected readonly initial = computed(() => (this.name().trim().charAt(0) || '?').toUpperCase());

Test setup and defaults

it('creates a decorative large avatar with a placeholder initial', () => {
  expect(fixture.componentInstance).toBeTruthy();
  expect(host.classList.contains('avatar')).toBe(true);

Testing the computed

The table is the contract

const map: Record<string, string> = {
  primary: 'avatar--q',
  leaf: 'avatar--s',
  sky: 'avatar--e',
  sun: 'avatar--m',
  indoor: 'avatar--indoor',
};
for (const [tone, cls] of Object.entries(map)) {
  fixture.componentRef.setInput('tone', tone);
  fixture.detectChanges();
  expect(host.classList.contains(cls)).toBe(true);
}

Plus mirrors the size to a host class · no test yet for src

Pitfalls

  • Adding an avatar--lg class — large is the base
  • Renaming q / s / e / m — breaks mock parity
  • A real alt inside an aria-hidden host
  • Side effects inside computed()

Things to remember

Decorative host: aria-hidden
Class binding per modifier
Mock class names verbatim
computed() for the initial
Background + foreground pairs
Tone → class table as contract
