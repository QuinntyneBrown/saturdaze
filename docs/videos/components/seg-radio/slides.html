Coding sd-seg-radio

A segmented radio group that plugs into Angular forms.

Where it is used

    <sd-seg-radio
      label="Which day"
      name="day"
      [options]="days"
      [ngModel]="day()"
      (ngModelChange)="day.set($event)"
    />

Also add-to-day-dialog ("Which day") and commitment-dialog ("Day").

What you will build

  • A labelled group of two or three native radios
  • One string value, read and written through the forms API
  • The mock's BEM classes: .field, .seg-radio, .seg-radio__opt
  • No custom keyboard code

The option type and an id counter

export interface SegRadioOption {
  readonly value: string;

let nextSegRadioId = 0;

Inputs stay inputs: no host attributes for label or value. Only classes and ARIA state go on the host (ADR-009).

Inputs, signals and a computed

export class SegRadio implements ControlValueAccessor {
  readonly label = input<string>('');
  readonly options = input<readonly SegRadioOption[]>([]);

  protected readonly id = `sd-seg-radio-${nextSegRadioId++}`;
  protected readonly labelId = `${this.id}-label`;
  protected readonly value = signal<string>('');
  protected readonly disabled = signal<boolean>(false);
  protected readonly three = computed(() => this.options().length >= 3);

  private onChange: (value: string) => void = () => {};
  private onTouched: () => void = () => {};

computed() for derived state

  protected readonly three = computed(() => this.options().length >= 3);
  • Cached — recalculates only when options() changes
  • Drives the seg-radio--3 modifier class

The methods

  protected pick(v: string): void {
    if (this.disabled()) return;
    this.value.set(v);
    this.onChange(v);
    this.onTouched();
  }

  writeValue(value: string | null): void {
    this.value.set(value ?? '');
  }

registerOnChange / registerOnTouched store callbacks; setDisabledState writes the signal.

    <label class="seg-radio__opt">

        type="radio"
        [name]="id"

        [checked]="option.value === value()"

Pitfalls

  • There is no value input — bind with ngModel or a form control
  • Duplicate option values break track option.value
  • More than three options: only 2- and 3-column layouts exist

Things to remember

NG_VALUE_ACCESSOR + forwardRef
Form-owned state in signal()
computed() for the modifier
Native radios, one shared name
:has styles checked + focus
Spec drives the CVA methods
