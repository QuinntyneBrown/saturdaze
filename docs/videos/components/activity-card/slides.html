Coding sd-activity-card

Signal inputs, an output and projected chips.

Where it lives

<sd-activity-card
  [title]="activity.title"
  [meta]="activity.meta"
  [why]="activity.why"
  [icon]="activity.icon"
  [tone]="activity.tone === 'outdoor' ? 'leaf' : 'indoor'"
  [mapUrl]="activity.mapUrl ?? ''"
  [media]="activity.media"
  addable
  (addToDay)="addToDay(activity)"

Signal inputs with typed defaults

export class ActivityCard {
  readonly cardTitle = input<string>('', { alias: 'title' });
  readonly meta = input<string>('');
  readonly why = input<string>('');
  readonly icon = input<string>('tree');
  readonly tone = input<ActivityCardTone>('leaf');
  readonly mapUrl = input<string>('');

export type ActivityCardTone = 'leaf' | 'indoor';

alias: 'title'

Consumer writes

[title]="activity.title"

Class reads

cardTitle() — never confused with the native title

A flag and an output

  /** The place's primary photo; null shows the fallback tile. */
  readonly media = input<CardMedia | null>(null);
  /** Offer "Add to day" (L2-107). */
  readonly addable = input(false, { transform: booleanAttribute });
  /** "Add to day" was pressed. */
  readonly addToDay = output<void>();
}

<sd-activity-card addable> → true, not ''

What it doesn't need

computed()

No derived state

signal()

No local state

effect()

No side effects

A presentational card stays thin: inputs in, one output out.

Media, head and body

  <p class="card__body">{{ why() }}</p>
}
<div class="card__chips"><ng-content select="[slot=chips]" /></div>

One slot, declared once

@for (chip of activity.chips; track chip.label) {
  <sd-chip slot="chips" [tone]="chipTone(chip.tone)">
    …
  </sd-chip>
}

One @if per slotted node — an @if around several loses the slot (NG8011).

The footer

@if (mapUrl() || addable()) {
  <div class="card__footer">

        <sd-icon name="map" />

      <sd-button
        variant="primary"
        size="sm"

        [label]="'Add to day: ' + cardTitle()"

Defaults, content and tone

  • creates a photo-led card whose fallback tile is leaf-toned with a tree, and the title
  • renders the place line and the why
  • switches to the indoor tone and a custom icon
expect(tile.classList).toContain('media--leaf');
expect(tile.getAttribute('aria-hidden')).toBe('true');
expect(host.querySelector('.card__footer')).toBeNull();

The Map link and the slot

  • adds a Map link that opens in a new tab when the catalogue has one
  • labels the Map link with its glyph and text
  • projects chips into the chip row
expect(link.getAttribute('target')).toBe('_blank');
expect(link.getAttribute('rel')).toBe('noopener');
expect(link.classList.contains('btn--quiet')).toBe(true);

Not covered yet: addable and the addToDay output.

Pitfalls

  • Dropping booleanAttribute — bare addable stops working
  • One @if around several slotted chips
  • Wrapping the whole card in a link as well as Map
  • Renaming BEM classes the e2e locators depend on

Things to remember

Host carries card card--media
Typed signal inputs, alias: 'title'
booleanAttribute for flags
output() for Add to day
One chips slot, declared once
Card styles from a mixin, tokens by role
