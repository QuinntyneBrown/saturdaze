inject(), inputs and an output

export class ListItem {
  private readonly router = inject(Router, { optional: true });

  readonly rowTitle = input<string>('', { alias: 'title' });
  readonly subtitle = input<string>('');
  /** Render the subtitle above the title (a label over a value). */
  readonly subtitleFirst = input(false, { transform: booleanAttribute });
  readonly href = input<string>('');
  /** Render the row as a `<button>`; `pressed` emits on click. */
  readonly action = input(false, { transform: booleanAttribute });
  readonly chevron = input(false, { transform: booleanAttribute });
  /** Accessible name override for action rows (defaults to the row text). */
  readonly label = input<string>('');
  readonly pressed = output<void>();

Why rowTitle?

Field named title

Collides with the native title property on elements

rowTitle + alias: 'title'

Templates still write title="Sara"

Flags use booleanAttribute, so <sd-list-item action chevron> just works.

Plain clicks route in-app

  protected onAnchorClick(event: MouseEvent): void {
    if (this.router) navigateInApp(this.router, event, this.href());
  }
export function navigateInApp(router: Router, event: MouseEvent, href: string): void {
  if (!isPlainClick(event) || !isInAppHref(href)) return;
  event.preventDefault();
  void router.navigateByUrl(href);
}

Six tests

  1. creates a static listitem row
  2. renders title and subtitle and mirrors them to the host
  3. adds the trailing chevron glyph
  4. becomes a button that emits pressed when action is set
  5. becomes an in-app anchor when href is set and routes plain clicks
  6. projects leading, default and trailing content into the row

Fails if someone duplicates the slots per branch.

Pitfalls

  • Repeating ng-content per branch — content disappears
  • A title field without an alias
  • A click handler on a static row — use action or href
  • A toggle in the trailing slot of an action row

Things to remember

One body template + ngTemplateOutlet
div · anchor · button by input
booleanAttribute flags, alias: 'title'
output() for pressed
Optional inject(Router), plain clicks in-app
Six tests, including slot projection
