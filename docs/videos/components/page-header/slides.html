AGENTS.md · NG8011

A @if wrapping several [slot=…] nodes loses the slot — one @if per node.

  <sd-page-header
    title="Review submissions"
    [subtitle]="subtitle()"
    backHref="/family"
    backLabel="Family"
  />

The decorator

@Component({
  selector: 'sd-page-header',
  standalone: true,
  imports: [Button, Icon],
  templateUrl: './page-header.html',
  styleUrl: './page-header.scss',
  changeDetection: ChangeDetectionStrategy.OnPush,
  host: {
    class: 'page-header',
  },
})

No [attr.title]: a host title is a native tooltip (ADR-009).

inject() and four inputs

export class PageHeader {
  private readonly router = inject(Router, { optional: true });

  readonly pageTitle = input<string>('', { alias: 'title' });
  readonly subtitle = input<string>('');
  readonly backHref = input<string>('');
  readonly backLabel = input<string>('Back');

  protected onBack(event: MouseEvent): void {
    if (this.router) navigateInApp(this.router, event, this.backHref());
  }
}

What it doesn't need

  • output() — slotted buttons bring their own handlers
  • computed() — 'Back to ' + backLabel() is a simple expression
  • booleanAttribute — no flags; empty backHref means no back link

Pitfalls

  • One @if around several slotted nodes
  • Two primaries, or more than two quiet actions
  • An icon-only More without label
  • Laying out header buttons from the page

Things to remember

One header, the only h1
alias: 'title'; inputs stay off the host
Optional inject(Router)
Three slots, each declared once
Back link twice, shown once
Grid → flex, sized by --sd-btn-h
