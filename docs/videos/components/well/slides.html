Classes and ARIA state only (ADR-009)

A host title attribute is a native hover tooltip the mocks never had.

Three signal inputs, one alias

export class Well {
  readonly icon = input<string>('sparkle');
  readonly tone = input<WellTone>('default');
  readonly wellTitle = input<string>('', { alias: 'title' });
}

Compare icons by what they draw

/** The svg markup `sd-icon` draws for `name`, to compare against a rendered glyph. */
const glyph = (name: string): string => {
  const ref = TestBed.createComponent(Icon);
  ref.componentRef.setInput('name', name);
  ref.detectChanges();
  return (ref.nativeElement as HTMLElement).querySelector('svg')?.innerHTML ?? '';
};
const drawn = (icon: Element | null): string => icon?.querySelector('svg')?.innerHTML ?? '';

Pitfalls

  • No [attr.title] on the host — it is a native hover tooltip
  • Never wrap the content slot in a condition
  • Choose the tone for meaning: success, danger, brand
