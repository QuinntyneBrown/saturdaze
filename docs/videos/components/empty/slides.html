Coding sd-empty

An empty state with a disc, a heading and a call to action.

Where it is used

      <sd-empty
        warm
        icon="sparkle"
        tone="primary"
        [title]="emptyTitle()"
        body="Your commitments stay put. …"
        note="Or wait for Friday at 6pm."
      >
        <sd-button slot="cta" variant="primary" size="lg" (click)="plan()">
          <sd-icon name="sparkle" />
          Plan this weekend
        </sd-button>
      </sd-empty>

Also: past, review-submissions, shared-weekend pages

The decorator

@Component({
  selector: 'sd-empty',
  standalone: true,
  imports: [Disc],
  templateUrl: './empty.html',
  styleUrl: './empty.scss',
  changeDetection: ChangeDetectionStrategy.OnPush,
  host: {
    class: 'empty',
    '[class.empty--warm]': 'warm()',
    '[attr.aria-labelledby]': 'headingId',
  },
})

Six signal inputs

export class Empty {
  readonly emptyTitle = input<string>('Nothing here yet', { alias: 'title' });
  readonly body = input<string>('');
  readonly icon = input<string>('sparkle');
  readonly tone = input<DiscTone>('default');
  readonly warm = input(false, { transform: booleanAttribute });
  readonly note = input<string>('');

  protected readonly headingId = `sd-empty-${nextEmptyId++}`;
}

Share the type, don't copy it

import { Disc, DiscTone } from '../disc/disc';

A tone the disc doesn't support can't reach the empty state.

What it doesn't need

No computed()

Nothing derived beyond simple @if conditions.

No output()

The CTA is projected; the consumer's button handles its own click.

A unique id from a counter

let nextEmptyId = 0;
…
  protected readonly headingId = `sd-empty-${nextEmptyId++}`;
  • Plain constant, not a signal — never changes
  • Template: [id]="headingId" · host: [attr.aria-labelledby]

Proving the slots

Pitfalls

  • An output() for the CTA — project a button instead
  • A boolean input without booleanAttribute
  • Repeating [slot=cta] in @if branches

Things to remember

Composes sd-disc, reuses DiscTone

booleanAttribute for bare warm
