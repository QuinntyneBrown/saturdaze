The decorator

@Component({
  selector: 'sd-auth-shell',
  standalone: true,
  imports: [RouterLink],
  templateUrl: './auth-shell.html',
  styleUrl: './auth-shell.scss',
  changeDetection: ChangeDetectionStrategy.OnPush,
  host: {
    class: 'auth',
    '[class.auth--stack]': 'stack()',
  },
})

One boolean input

export class AuthShell {
  /** Top-aligned (several stacked cards) instead of vertically centred. */
  readonly stack = input(false, { transform: booleanAttribute });
}

App

Host bindings read signals

No @HostBinding

The host map reads stack()

Nothing to derive

OnPush + signal input → the class stays in sync. No [attr.stack]: only classes and ARIA on the host (ADR-009).

Accessible footer

linkhref
Terms/legal
Privacy/legal#privacy
Back to Saturdaze/

Dots are aria-hidden: a screen reader hears three links, no punctuation.

routerLink in a library component

  • Navigation stays inside the SPA
  • The anchor still renders a real href
  • Tests must provideRouter([])

Stack and projection

  • top-aligns stacked cards
  • projects the card between the brand and the footer

Pitfalls

  • No provideRouter in the spec → routerLink fails
  • Plain hrefs → full app reload on every click
  • Dropping aria-hidden from the mark or the dots

Things to remember

The host is the page: auth
stack → a class, not an attribute
booleanAttribute for the bare flag
routerLink + provideRouter in tests
Decoration is aria-hidden
100svh + layout gutter token
