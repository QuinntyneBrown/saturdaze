Coding sd-list

A list host, one boolean input, and a padding knob the rows read.

The decorator

@Component({
  selector: 'sd-list',
  standalone: true,
  templateUrl: './list.html',
  styleUrl: './list.scss',
  changeDetection: ChangeDetectionStrategy.OnPush,
  host: {
    class: 'list',
    role: 'list',
    '[class.list--card]': 'card()',
    '[attr.card]': 'card() ? "" : null',
  },
})

Mirror state like a native attribute

card = true

<sd-list class="list list--card" role="list" card="">

card = false

<sd-list class="list" role="list">
null removes the attribute

One boolean input

export class List {
  readonly card = input(false, { transform: booleanAttribute });
}

What it doesn't need

  • computed() — nothing is derived
  • output() — rows handle interaction
  • imports — the template is only <ng-content />

Defaults and the card state

  it('creates a plain list', () => {
    expect(fixture.componentInstance).toBeTruthy();
    expect(host.classList.contains('list')).toBe(true);
    expect(host.getAttribute('role')).toBe('list');
    expect(host.classList.contains('list--card')).toBe(false);
    expect(host.getAttribute('card')).toBeNull();
  });

  it('draws the card surface when asked', () => {
    fixture.componentRef.setInput('card', true);
    fixture.detectChanges();
    expect(host.classList.contains('list--card')).toBe(true);
    expect(host.getAttribute('card')).toBe('');
  });

Items are direct children

  it('projects list items as its direct children', () => {
    const wrapper = TestBed.createComponent(HostCmp);
    wrapper.detectChanges();
    const list = (wrapper.nativeElement as HTMLElement).querySelector('sd-list') as HTMLElement;
    expect(list.classList.contains('list--card')).toBe(true);
    const items = Array.from(list.children);
    expect(items.length).toBe(3);
    expect(items.every((i) => i.getAttribute('role') === 'listitem')).toBe(true);
    /* … titles: 'Quinn', 'Sara', 'Eli' */
  });

Pitfalls

  • Ghost rows or other content inside the list — wrong item count
  • A boolean input without booleanAttribute
  • ::ng-deep into rows instead of the --sd-list-pad-x knob

Things to remember

Host is the list: class + role="list"
booleanAttribute, mirrored as card=""
Card surface from tokens by role
--sd-list-pad-x passes padding down
One slot, declared once
Spec: defaults, card, direct children
