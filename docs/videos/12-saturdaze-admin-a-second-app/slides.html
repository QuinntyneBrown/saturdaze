A family account meets the gate

  • "This account can't use Saturdaze Admin"
  • Nothing from the catalog was loaded
  • Sign out revokes the session

The boundary is on the server

[ApiController]
[Route("api/admin")]
[Authorize(Policy = "Admin")]
public sealed class AdminPhotosController : ControllerBase

// Program.cs
builder.Services.AddAuthorization(o =>
{
    o.AddPolicy("Admin", p => p.RequireRole(nameof(UserRole.Admin)));
    o.FallbackPolicy = new AuthorizationPolicyBuilder(JwtBearerDefaults.AuthenticationScheme)
        .RequireAuthenticatedUser()
        .Build();
});

Things to remember

A second Angular app on its own host; admin code never reaches families.
Shared components and api; services bound to tokens; no copied code.
One account, one API: the gate is a courtesy, the Admin policy is the boundary.
Side navigation from 1024 px, top bar below.
The admin deploy runs after migrations, with its own token.
