D21 names the consequence

function removalConsequence(member: MemberRow): string {
  if (member.access === 'Account')
    return `${member.name} will be signed out and will no longer be able to sign in.`;
  if (member.access === 'Invited' && member.email)
    return `The invite sent to ${member.email} will stop working.`;
  return 'Future weekends will not plan for them.';
}

Things to remember

D21 states the access consequence before the owner confirms.
Removal deletes the invitation, or the account and its sessions.
The family is read from the user's row each request: a removed member's tab gets 401 at once.
The owner can't be removed; the profile save can't drop a member with access.
