D41: the dividers that disappeared

A last-child rule stripped every row's hairline in the mocks

What drifted

<ul class="list">
  <li><a class="list__item">Quinn</a></li>   <!-- last child of its own li -->
  <li><a class="list__item">Sara</a></li>
</ul>
.list__item:last-child { border-bottom: 0; }  /* matches every row */

Why it matters

  • Rows run together; the card stops showing where one tap target ends
  • The design system had already fixed this in extraction; the mocks were out of step

The one-rule fix

.list__item:last-child { border-bottom: 0; }
.list > li:not(:last-child) > .list__item { border-bottom: 1px solid var(--sd-line); }
  • docs/mocks/styles/app.css; no new behaviour, so no acceptance test
  • sd-list-item in the app was already right (host :last-child)
  • Design-system list note reworded; D41 removed from the drift log

Before · Family mock

After · Family mock

Things to remember

  • A last-child rule on a row inside its own li matches every row
  • Divider on .list > li:not(:last-child) > .list__item
  • The product component was right; the mock drifted
  • Fix the mock, then delete the drift record
