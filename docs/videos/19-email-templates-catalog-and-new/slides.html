Four pieces of content

  • Subject and preheader: the inbox line
  • HTML body and plain-text body
  • Placeholders in all four: {{recipientName}}, {{resetLink}}
  • A sender fills them in at send time; the preview uses sample data

Key, category, status

public class EmailTemplate
{
    public string Key { get; set; } = string.Empty;          // account.password-reset
    public string Name { get; set; } = string.Empty;
    public EmailTemplateCategory Category { get; set; }      // fixed at creation
    public EmailTemplateStatus Status { get; set; }          // Draft · Active · Archived
    public string Subject { get; set; } = string.Empty;
    public string Preheader { get; set; } = string.Empty;
    public string HtmlBody { get; set; } = string.Empty;
    public string TextBody { get; set; } = string.Empty;
    public string SampleData { get; set; } = "{}";
    public bool IsSystem { get; set; }
    public int Version { get; set; }                         // +1 on every change
}

Things to remember

Subject, preheader, HTML and text, with {{placeholders}}.
Key and category are fixed; senders will look up by key.
System templates: seeded, never overwritten, archived or deleted.
New template starts from category content; marketing keeps unsubscribe.
Duplicate copies content into an ordinary draft.
