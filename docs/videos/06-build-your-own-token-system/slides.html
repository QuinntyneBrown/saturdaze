Step 4 · Alias generator

Two alias files

  (brand: BrandVariants): ColorTokens => ({
    colorNeutralForeground1: slate[17], // body ink
    colorBrandBackground: brand[80],
    colorBrandForeground2: brand[70],
    colorBrandBackground2: brand[160],

function roles(prefix, color) {
  return {
    [`${prefix}Background1`]: color.tint50,
    [`${prefix}Foreground1`]: color.shade40,
    /* … 4 more roles … */
  };
}

Check every Foreground1 on its Background1 for AA — then write the pairing rule down.

Step 10 · Runtime theming + docs

A provider in ~50 lines

Does

  • takes a PartialTheme
  • themeToCssVariables
  • sets each property on its host
  • removes ones the new theme dropped

Docs from the theme

Storybook pages and the manager theme import the theme object — never parse CSS.

Pitfalls

  • Naming by value (coral, primary)
  • Components reading globals
  • Hand-editing generated files
  • No formatting in the generator
  • var() in media queries — doesn't work
  • Provider wrapping the whole app
  • Dark theme by copy-paste → write createDarkTheme(brand)

Things to remember

Borrow a proven model; record the decision
Types → globals → aliases → flat theme
Serialiser tested and shared with the provider
One script: write + check, Prettier, CI
Migrate by CSS property; write rules down
Document from the theme object
